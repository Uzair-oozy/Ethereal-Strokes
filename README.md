# Ethereal-Strokes
An Art Gallery website made using HTML, CSS and JS

## Ethereal Strokes — Art Gallery Website

A simple static portfolio/shop website built with HTML, CSS, and JavaScript. It showcases art pieces, seller information, and artist profiles with a clean gallery layout and responsive design.

### What this project includes

- index.html — Landing page and about section for the gallery
- gallery.html — Shop page with featured artwork cards
- artist.html — Artist spotlight/contact page
- index.css — Shared styling for layout, gallery cards, header, footer, and responsive behavior
- Art-Gallery.js — Basic cart logic for adding an item and calculating total

### Core features

- **Home page**
  - Brand header with navigation
  - Banner image section
  - About section describing the gallery concept
  - Best-seller artwork card with price and add-to-cart button
  - Cart counter and total display area

- **Gallery page**
  - Grid layout of featured paintings
  - Artwork details with title, artist, and description
  - Consistent gallery item styling and responsive card layout

- **Artist page**
  - Featured artist biographies
  - Visual artist cards with images and descriptions

- **Responsive design**
  - Mobile-friendly layout using CSS grid
  - Adaptive navigation and gallery card stacking for smaller screens

### Technical details

- Uses semantic HTML5 structure
- Styling with a single CSS file
- Gallery grid powered by `display: grid`
- Basic visual interaction with hover transitions
- JavaScript cart prototype records item count and total price

### Notes

- Project name appears as **Ethereal Strokes**
- Navigation links connect all pages for a simple multi-page portfolio
- Art-Gallery.js contains the shopping cart behavior, currently implemented as a simple alert-based demo
